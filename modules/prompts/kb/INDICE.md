# I manuali di COBRA

Ogni manuale è un file a parte. Nel prompt ci va solo questo indice: il testo
completo arriva quando serve, chiesto con `leggi_manuale("nome")`.

| nome | quando serve |
|---|---|
| `ricerca` | devi cercare qualcosa: dove andare, come costruire l'URL, cosa evitare |
| `navigazione` | devi aprire, leggere, scorrere o capire una pagina |
| `moduli` | devi compilare campi, scegliere da elenchi, spuntare caselle |
| `scrivere-ovunque` | devi scrivere un messaggio o compilare qualcosa su un sito qualsiasi, anche mai visto |
| `raccolta` | devi mettere insieme più soggetti (aziende, voli, hotel, articoli) |
| `consegna` | devi produrre un file, un report, un foglio di calcolo |
| `voce` | stai parlando ad alta voce |
